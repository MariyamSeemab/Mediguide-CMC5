## 🎯 How to Use (Step by Step)

1. **First Time Setup**:
   - Go to "Period Tracker" tab
   - Set your last period date
   - Adjust cycle length if needed (default 28 days)
   - Adjust period duration if needed (default 5 days)

2. **Daily Logging**:
   - Go to "Period Tracker" tab
   - Select your mood
   - Track water intake with +/- buttons
   - Click symptoms you're experiencing
   - Select flow intensity if on period
   - Add notes if desired
   - **Click "💾 Save Today's Log" button**

3. **View Calendar**:
   - Go to "Calendar" tab
   - See color-coded predictions
   - Click any day to log data for that date

4. **Check Analytics**:
   - Go to "Analytics" tab
   - See your cycle predictions
   - View insights after logging 7+ days

5. **Get AI Help**:
   - Go to "AI Companion" tab
   - Ask questions in chat
   - Select symptoms for pain relief advice
   - View nutrition and self-care tips
