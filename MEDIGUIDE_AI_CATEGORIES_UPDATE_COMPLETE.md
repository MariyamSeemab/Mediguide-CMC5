## Emergency Detection (Unchanged - Top Priority)

The system still checks for emergencies FIRST before any category classification:
- Chest pain / Heart attack
- Breathing difficulty / Respiratory distress
- Stroke signs (FAST)
- Severe bleeding
- Seizures / Convulsions
- Loss of consciousness
- Suicidal thoughts / Self-harm
- Severe allergic reaction (anaphylaxis)
- Severe burns
- Poisoning / Overdose

## Response Format (Unchanged)

All categories continue to follow the MediGuide AI format:
```
**Understanding:** [Brief summary]
**Possible Reasons:** [Category-specific possibilities]
**Recommended Action:** [Self-care/Doctor visit/Emergency]

```
