1. **Language Switcher** - Urdu with India flag 🇮🇳
2. **No RTL Layout** - Keeps LTR structure
3. **Urdu Numerals** - Auto-converts numbers
4. **Base File** - `ur.json` created with English text

## 📋 Translation Workflow

1. Open `src/translations/ur.json`
2. Find English value
3. Replace with Urdu translation
4. Save file
5. Test in browser
6. Repeat for all values
