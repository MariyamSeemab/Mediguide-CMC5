## Expected Response Format

Every response should include:

1. **Possible Medical Condition**
2. **Recommended Specialist**
3. **General Guidance**
4. **Common Medicines (General Guidance Only)**
5. **Basic Precautions**
6. **Emergency Warning**
7. Doctor referral link (when applicable)
8. Safety Note

---

## Emergency Inputs to Test

These should trigger special emergency responses:

```
I am having shortness of breath.
My leg is bleeding heavily.
I have severe chest pain.
I'm pregnant with severe abdominal pain and bleeding.
```

## Quick Verification Checklist

For each input, verify:
- [ ] Correct category detected
- [ ] All 6 sections present
- [ ] Doctor referral link (if applicable)
- [ ] Safety disclaimer included
- [ ] No diagnosis language
- [ ] No medication prescriptions
- [ ] Calm, professional tone
