# Skin Disease AI Assistant

A web-based application that uses Groq's Llama vision model to analyze skin condition images.

## Setup

1. Open `script.js` and replace `YOUR_GROQ_API_KEY_HERE` with your actual Groq API key
2. Open `index.html` in a web browser

## Usage

1. Click the upload area or drag and drop an image
2. Click "Analyze Image" to get AI-powered analysis
3. Review the results and recommendations

## Features

- Clean, modern UI
- Drag and drop image upload
- Real-time image preview
- AI-powered skin condition analysis
- Mobile responsive design

## Important

This tool is for informational purposes only. Always consult healthcare professionals for proper medical diagnosis and treatment.
